Session 1: Fine-tune a model

Everyone does this on their own. One GPU each.

01

Log in to the supercomputer portal

Go to morehouse.tapis.io and sign in with your TACC username, password, and the code from your authenticator app.

02

Start your GPU session

Click Apps, choose the Jupyter app for Vista, click Submit Job, then choose Use Guided Job Launcher. Click through each section and change only these:

SectionFieldSet it to
Execution OptionsBatch Logical Queuegh
Execution OptionsNodes1
Execution OptionsMax minutes100
Scheduler OptionsTACC Resource Allocation-A TRA25008
Scheduler OptionsReservation Name--reservation inspireGPU

Leave everything else as it is, then click Submit.

03

Open Jupyter

Click Jobs in the left panel and click your job. When it is running, click the button to open Jupyter. If there is no button, open the output file tapisjob.out, copy the address after JUPYTER_URL, and open it in a new tab.

04

Get the workshop

In Jupyter, click File → New → Terminal and type:

cd $WORK
git clone https://github.com/ashleyscruse/hpc-finetune-workshop

Then open hpc-finetune-workshop/notebooks/01-fine-tune.ipynb.

05

Run it

Click a cell and press Shift + Enter. Go top to bottom. A cell is done when the [*] beside it turns into a number.

WRITE THESE DOWN  Your accuracy after training and how many seconds training took. You need both this afternoon.
06

Before lunch: end your session

In the portal, open your job and cancel it. This frees your GPU for the afternoon. Your results are saved.

Session 2: Make it faster

You work in a team. Pick your roles first.

RoleJob
DriverThe only person who starts a session. Runs the cells.
RecorderWrites down the team's predictions before anything runs, then the results.
SkepticAsks why it isn't exactly 4 times faster and checks the math.
ReporterBrings the team's numbers to Lightning Shares.
01

Driver: start a 4-node session

Same as the morning, with one change: Nodes is 4.

SectionFieldSet it to
Execution OptionsBatch Logical Queuegh
Execution OptionsNodes4
Execution OptionsMax minutes90
Scheduler OptionsTACC Resource Allocation-A TRA25008
Scheduler OptionsReservation Name--reservation inspireGPU

Leave everything else as it is, then click Submit.

02

Open the notebook

Open Jupyter the same way as this morning. Your workshop folder is already there. Open hpc-finetune-workshop/notebooks/02-make-it-faster.ipynb and run it top to bottom.

FOR LIGHTNING SHARES  1-node time · 4-node time · speedup · accuracy · what surprised your team.
03

When you're done: end your session

Driver: cancel the job in the portal so the nodes are freed.
